### Trabalho

**Software**
- Plataforma de operação de crédito usada por cerca de 130 pessoas, substituindo um legado em ASP clássico: Clean Architecture, DDD, pirâmide de testes completa, CI/CD para homologação e produção e infraestrutura no Azure e IIS.
- Sistemas de controle de acesso integrados a hardware (catracas, biometria, cancelas e balanças), gestão de processos para prefeituras e modelagem de um ERP interno.

**Software com IA**
- Engenharia de contexto para agentes de código: Claude Code configurado com plugins e skills que levam ao agente a arquitetura, as convenções e os padrões de teste do projeto, com revisão de código antes de produção.

**Produtos de IA**
- Agente de consulta a dados em linguagem natural (text-to-SQL): orquestrador com busca semântica sobre o catálogo de tabelas (Semantic Kernel Memory), geração de T-SQL com DeepSeek Coder, execução isolada via servidor MCP somente leitura e agente analítico com contexto do negócio.
